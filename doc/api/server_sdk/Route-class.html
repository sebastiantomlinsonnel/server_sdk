Route

Route class

A path in the API, like /todos or /todos/<id>.

Routes nest like commands in a CLI: a child's path is added to its parent's, and it inherits the parent's params. A route's help becomes the docs group for its endpoints and every child that has no help of its own.

Route(
  '/todos',
  help: 'Todos',
  endpoints: [
    Endpoint.get(run: (_) => todos),               // GET /todos
  ],
  routes: [
    Route(
      '/<id>',
      params: [const PathParam.int('id')],
      endpoints: [
        Endpoint.get(run: (input) => find(input)),  // GET /todos/<id>
        Endpoint.delete(run: (input) => remove(input)),
      ],
    ),
  ],
);
