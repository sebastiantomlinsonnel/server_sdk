BodyField

BodyField class

A field of the JSON object sent as the request body.

When an endpoint declares any body fields, the body must be a JSON object (an empty body counts as {}). Fields that aren't declared are ignored, but stay readable through ApiInput.json.

Endpoint.post(
  body: [
    const BodyField.string('title', required: true),
    const BodyField.string('priority', allowed: ['low', 'high']),
    const BodyField.list('tags'),
  ],
  run: (input) => create(input.body.toMap()),
);
