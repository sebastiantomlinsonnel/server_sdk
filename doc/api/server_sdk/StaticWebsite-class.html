StaticWebsite

StaticWebsite class

A folder of static files.

Only GET and HEAD are answered; other methods get 405.

Server(
  name: 'site',
  prefix: '/api',
  website: StaticWebsite(
    'public',
    spaFallback: true,
    cacheControl: 'max-age=3600',
  ),
);
