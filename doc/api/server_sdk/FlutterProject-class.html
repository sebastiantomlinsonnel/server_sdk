FlutterProject

FlutterProject class

A Flutter app, served from its build/web folder and built when build says so.

Serving uses the FlutterWebsite defaults: unknown pages get index.html, files are revalidated on each load, and crossOriginIsolated adds the headers multi-threaded --wasm builds need.

final server = Server(
  name: 'my app',
  prefix: '/api', // required when there's a website
  routes: [...],
  website: FlutterProject(
    '../app',
    build: FlutterBuild.ifChanged,
    dartDefines: {'API_URL': '/api'},
  ),
);

await server.serve(); // builds ../app if needed, then serves both
