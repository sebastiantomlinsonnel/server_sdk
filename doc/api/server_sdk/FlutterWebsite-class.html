FlutterWebsite

FlutterWebsite class

The output of flutter build web, with the right defaults for it:

  • unknown pages get index.html, so path URLs work on reload;
  • files are revalidated on each load, since Flutter's file names don't change between builds;
  • with crossOriginIsolated, the headers multi-threaded --wasm builds need are sent.
