Gets the website ready (building it when needed), then starts listening and logs the website, API and docs URLs with cmdline.

  • host defaults to every IPv4 address (0.0.0.0). port defaults to the PORT environment variable, then 8080.
  • securityContext serves HTTPS instead of HTTP.
  • shared lets several isolates bind the same port; backlog is the listen queue length.
  • idleTimeout closes idle keep-alive connections after that long.
  • poweredByHeader is sent as x-powered-by; null leaves it out.
  • banner false starts quietly, without the startup lines.

Throws a FlutterBuildException when a FlutterProject fails to build, and a StateError when the website's folder doesn't exist.

Future<HttpServer> serve({
  Object? host,
  int? port,
  SecurityContext? securityContext,
  bool shared = false,
  int? backlog,
  Duration? idleTimeout,
  String? poweredByHeader = 'Dart with package:shelf',
  bool banner = true,
}) async {
  await website?.prepare();
  final prefix = joinPaths('', this.prefix);
  final docsUrl = _docsUrl;

  return startServer(
    handler, // Built before binding, so a missing website fails early.
    host: host,
    port: port,
    securityContext: securityContext,
    shared: shared,
    backlog: backlog,
    idleTimeout: idleTimeout,
    poweredByHeader: poweredByHeader,
    showBanner: banner,
    banner: (base) => [
      if (website != null) 'Website at $base/',
      'API $name${version == null ? '' : ' $version'} '
          'at $base${prefix == '/' ? '' : prefix}',
      if (docsUrl != null) 'Docs at $base$docsUrl',
    ],
  );
}
