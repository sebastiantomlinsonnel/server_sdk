Server

Server class

An HTTP API described as a tree of Routes.

Handles the plumbing for you:

  • Path, query and body values are checked against their declarations; a mistake answers 400 with {"error": "..."}.
  • Unknown paths answer 404, known paths with the wrong method 405.
  • run results are sent as JSON; null answers 204.
  • A thrown ApiError answers with its status, shaped by errorBody; any other exception goes to onError, which by default logs it with cmdline and answers 500.
  • GET <prefix>/health, and GET <prefix>/version when version is set. Move them with healthPath and versionPath, turn them off with null, or declare your own to replace them.
  • GET <prefix>/openapi.json and GET <prefix>/docs describe every route, unless docs is false. Move them with openApiPath and docsPath.
  • HEAD requests are answered by the matching GET endpoint.
  • With a website, every path outside prefix is served from it, so the site and the API share one origin.
final api = Server(
  name: 'todos',
  version: '1.0.0',
  help: 'A small todo list.',
  prefix: '/api',
  middleware: [Server.logRequests(), Server.cors()],
  routes: [
    Route(
      '/todos',
      help: 'Todos',
      endpoints: [
        Endpoint.get(run: (_) => todos),
      ],
    ),
  ],
);

await api.serve(port: 3000);
